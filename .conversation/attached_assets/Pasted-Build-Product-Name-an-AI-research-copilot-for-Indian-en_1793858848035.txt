=== DATA CONNECTORS (one Python module each, common interface) ===
Each connector returns a normalized Paper object: id, doi, title, abstract (nullable), authors[], year, venue, publisher, type, citation_count, references[], is_open_access, oa_pdf_url, license, source, source_url.
Deduplicate across sources by DOI first, then by normalized title + year.
1. OpenAlex (primary) — https://api.openalex.org/works (search, filters, cited_by, topics). Requires api_key. Cache results; respect the daily budget.
2. Crossref — https://api.crossref.org/works (DOI metadata, references). Send mailto for the polite pool.
3. Semantic Scholar Graph API — https://api.semanticscholar.org/graph/v1 (search, TLDR, citations, recommendations). Show "Data from Semantic Scholar" attribution wherever S2 data is displayed.
4. arXiv — http://export.arxiv.org/api/query (CS/EE/physics preprints). Always link back to arXiv for full text. Max 1 request every 3 seconds.
5. CORE — https://api.core.ac.uk/v3 (open-access full texts).
6. Unpaywall — https://api.unpaywall.org/v2/{doi}?email=... (find a legal free PDF for a DOI).
7. OpenCitations — https://opencitations.net/index/api/v2 (citation links, CC0).
8. DOAJ — https://doaj.org/api (open-access journals list; used for journal checks).
9. dblp — https://dblp.org/search/publ/api (computer science papers, CC0).
Add a source registry table (name, licence, commercial_ok, attribution_text, rate_limit) and make every connector check it.

=== NON-NEGOTIABLE RULES ===
1. NEVER invent a citation. Every reference the AI writes must map to a Paper row with a real DOI or source ID returned by a connector. After generation, run a citation verifier that re-checks each DOI against Crossref/OpenAlex; remove or flag anything that fails.
2. Every AI sentence that makes a factual claim carries an inline citation the user can click to open the source.
3. Never host or serve paywalled PDFs. Only store full text when the licence allows (CC0, CC BY, CC BY-SA; arXiv per-paper licence; PMC commercial-use subset). Otherwise show metadata + a link to the publisher.
4. User-uploaded PDFs are private to that user (or their project team) and never added to the shared index.
5. When a paper has no abstract (common for paywalled Springer/Elsevier papers), still show it in search using title, keywords and citations, with a button "Upload your PDF" and a "View on publisher site" link.
6. Add an AI-use disclosure line to every exported paper/thesis draft. Position the tool as a writing assistant; the researcher is the author.
7. Log every external API call (source, endpoint, latency, status) for cost and rate-limit monitoring.
